# Data-205_2026_CAPSTONE

**Basic Overview**

This project is about discovering the relationship between poverty and educational attainment within Montgomery County, and Maryland in general. Throughout this project, I will be looking at how different socioeconomic characteristics impact educational attainment, as well as how these issues are distributed across demographics and counties.





**Tools**

This project is will primarily be conducted in R studio.




**Datasets**

There are two primary datasets being used for this project, one pulled from DataMontgomery and the other straight from MCPS.
